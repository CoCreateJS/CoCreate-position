CoCreate Position

A small interactive guide to positioning, queries, and insertion references.

Move an element

Drag the panel by its header into the left or right snap area. The panel uses snappable-query to select its snap containers.

Drag this panel
Its position can be controlled with CSS and the Position events. 
<div draggable snappable-query="$top .snap-area[]">...</div>

Overlay a box with position-query

Click the trigger to show a box that matches its margins and size. 

<button position-events="click" position-query="$this" position-element="$top #target-box">Show target box</button>
<div id="target-box" hidden></div>

Follow hovered content in a page and an iframe

Hover headings, paragraphs, or inline content in either editor. The outline follows the hovered text while the toolbar controls sit just above its bounds.

Page editor

Hover a heading

Move across this rich text sample to see the toolbar follow each element.

Nested content gives the hover query several matching ancestors.

Bold text and italic text are separate hover targets. 

<div position-events="hover" position-query="*:hover[]" position-element="$top #hover-format-toolbar" position-box="text">...</div>
<iframe position-events="hover" position-query="$contentDocument *:hover[]" position-element="$top #hover-format-toolbar" position-box="text">...</iframe>
<div id="hover-format-toolbar" class="hover-position-toolbar" hidden>
  <div class="hover-position-tools">...toolbar controls...</div>
  <div class="hover-position-outline"></div>
</div>
